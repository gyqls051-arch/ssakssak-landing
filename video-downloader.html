설치 방법

  1. 위 다운로드 버튼 클릭 → 받은 SsakSsakKimchiDownloader.exe 실행
  2. 처음 실행 시 Windows 보호 화면이 뜨면 추가 정보 → 실행 (서명되지 않은 개인 개발 프로그램이라 나오는 정상 안내)
  3. 첫 실행 때 필요한 파일(ffmpeg)을 자동으로 1회 받습니다 (인터넷 필요)
  4. 영상 링크를 칸에 붙여넣으면 정보 팝업 → 화질·포맷 고르고 다운로드
