싹싹김치 캡처

화면 캡처·녹화·GIF·OCR을 한 손 단축키로

⬇ Windows용 다운로드 (무료)
v1.0.4 · Windows 10/11 · 설치형 약 91MB · 무설치 포터블 ZIP도 있어요

주요 기능

4가지 캡처부분 · 창 · 전체 · 스크롤(긴 페이지)
화면 녹화 + GIFMP4 녹화, GIF 변환 · 하드웨어 인코딩 자동
OCR 글자 추출화면 속 글자를 드래그로 텍스트화
색상 추출픽셀 색을 HEX/RGB로 바로 복사
거리 측정화면 요소 간격을 px로 측정
한 손 단축키Alt+1~9로 모든 기능 즉시 실행

※ 디자이너·프론트엔드 개발자에게 특히 좋아요. 캡처 후 자동 저장·클립보드 복사, 도크 UI에서 원클릭 실행.

기본 단축키

Alt+1 부분 캡처Alt+2 전체 캡처Alt+3 창 캡처 Alt+4 스크롤 캡처Alt+5 색 추출Alt+6 거리 측정 Alt+7 OCRAlt+8 화면 녹화Alt+9 GIF 녹화

※ 단축키는 트레이 메뉴에서 자유롭게 바꿀 수 있어요.

설치 방법

  1. 위 다운로드 버튼 클릭 → 받은 Setup_SsakKimchiCapture.exe 실행 (포터블 ZIP은 압축만 풀면 끝)
  2. 처음 실행 시 Windows 보호 화면이 뜨면 추가 정보 → 실행 (서명되지 않은 개인 개발 프로그램이라 나오는 정상 안내)
  3. 설치 후 화면 가장자리의 도크 또는 Alt+1(부분 캡처)로 바로 시작
  4. 캡처물은 내 폴더/.ssakkimchi/captures에 저장돼요 (도크 우클릭으로 변경 가능)
